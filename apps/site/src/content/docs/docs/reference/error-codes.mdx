Errors come back as `application/problem+json` with a stable `code`. Match on `code`, not on the message: codes are never renamed or reused.

```json
{
  "type": "about:blank",
  "title": "this access can't write",
  "status": 403,
  "code": "read_only",
  "detail": "sqlite3: attempt to write a readonly database"
}
```

| Code | HTTP status | Meaning |
|---|---|---|
| `bad_request` | 400 Bad Request | The request body or a parameter is malformed. |
| `invalid_name` | 400 Bad Request | A name doesn't match `[a-z0-9][a-z0-9-]{0,62}`. |
| `empty_statement` | 400 Bad Request | The SQL text holds no statement. |
| `multiple_statements` | 400 Bad Request | `query` got more than one statement. Use `batch` for several. |
| `invalid_params` | 400 Bad Request | The parameters don't match the statement's placeholders. |
| `sql_error` | 400 Bad Request | SQLite rejected the statement. `detail` has SQLite's message. |
| `constraint_violation` | 409 Conflict | A UNIQUE, NOT NULL, CHECK or foreign key constraint failed. |
| `statement_denied` | 403 Forbidden | The statement uses something Lumbung doesn't allow: ATTACH, VACUUM INTO, transaction control, temp objects, a pragma off the allowlist or a denied function. |
| `read_only` | 403 Forbidden | The token can only read, and the statement writes. |
| `statement_timeout` | 408 Request Timeout | The statement ran past the statement timeout and was cancelled. Nothing it wrote was kept. |
| `value_too_large` | 413 Request Entity Too Large | A string, blob or statement is larger than its limit. |
| `result_too_large` | 413 Request Entity Too Large | The result has more rows or bytes than the limit. Nothing partial is returned and writes are rolled back. |
| `memory_limit` | 422 Unprocessable Entity | The statement needed more memory than one connection may use. |
| `branch_size_limit` | 507 Insufficient Storage | The write would grow the branch past its size limit. |
| `instance_quota_exceeded` | 507 Insufficient Storage | The write would grow the instance past its total size quota. |
| `insufficient_disk` | 507 Insufficient Storage | The host disk has less free space than the configured minimum. |
| `database_not_found` | 404 Not Found | No database with that name or id. |
| `branch_not_found` | 404 Not Found | No branch with that name or id in this database. |
| `name_taken` | 409 Conflict | Another database or branch already has that name. |
| `limit_reached` | 409 Conflict | The instance already has the most databases, or the database the most branches, allowed. |
| `busy` | 503 Service Unavailable | The branch stayed locked longer than the busy timeout. Retry. |
| `unavailable` | 503 Service Unavailable | The engine can't serve: for example meta.db is newer than this binary. |
| `internal` | 500 Internal Server Error | Something failed inside the engine. The log has details. |
