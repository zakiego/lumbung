lumbung talks to a Lumbung engine over its REST API.

Connection settings come from flags, then LUMBUNG_URL, LUMBUNG_TOKEN, LUMBUNG_DATABASE and LUMBUNG_WORKSPACE, then the profile saved by `lumbung login`.

A token for a workspace acts in that workspace. An instance token acts in the default workspace, or in the one --workspace names.

Every command takes these flags:

```text
      --json               print JSON instead of tables
      --profile string     saved profile to use
      --token string       API token (or LUMBUNG_TOKEN)
      --url string         engine URL (or LUMBUNG_URL)
  -w, --workspace string   workspace to act in, by name or id (or LUMBUNG_WORKSPACE); only an instance token needs it
  -y, --yes                don't ask before destructive actions
```

## lumbung branch

List, create, delete, reset, promote and diff branches.

### lumbung branch create

Create a branch as a copy of another branch or a snapshot.

```text
lumbung branch create NAME [flags]
```

```text
      --db string              database name or id (default: the profile's)
      --expires-in-days int    delete the branch automatically after this many days
      --from string            branch to copy (default: the default branch)
      --from-snapshot string   snapshot id to copy instead
      --protected              protect the branch from delete and reset
```

```sh
lumbung branch create pr-42 --db app --expires-in-days 7
```

### lumbung bucket move

Move a bucket to another workspace.

Moves a bucket from the workspace the command acts in to another one. Needs an instance admin token. Every token that reached the bucket is revoked: make new ones in the new workspace.

```text
lumbung bucket move NAME [flags]
```

```text
      --to string   the workspace to move it to, by name or id
```

### lumbung bucket update

Change a bucket's name, public read access or CORS origins.

```text
lumbung bucket update NAME [flags]
```

```text
      --cors strings   origins a browser may call the S3 API from (comma-separated; empty clears)
      --name string    rename the bucket
      --private        require a token to read objects
      --public         let anyone read objects without a token
```

```sh
lumbung bucket update photos --public
lumbung bucket update photos --cors https://app.example.com
```

### lumbung export

Download a branch as a SQLite file or SQL dump.

```text
lumbung export [flags]
```

```text
      --branch string   branch name or id (default: the database's default branch)
      --db string       database name or id (default: the profile's)
      --format string   db or sql (default "db")
  -o, --output string   write to this file instead of standard output
```

```sh
lumbung export --db app -o app.db
lumbung export --db app --format sql > dump.sql
```

### lumbung import

Import a SQLite file or SQL dump into a branch.

Imports FILE into a branch. A file starting with the SQLite header is imported as a database file, anything else as a SQL dump, unless --format says otherwise. By default the branch must have no tables; --mode replace overwrites it (not allowed on a protected branch).

```text
lumbung import FILE [flags]
```

```text
      --branch string   branch name or id (default: the database's default branch)
      --db string       database name or id (default: the profile's)
      --format string   db or sql (default: detected from the file)
      --mode string     empty or replace (default "empty")
```

```sh
lumbung import app.db --db app
lumbung import dump.sql --db app --branch staging --mode replace
```

### lumbung login

Save the engine URL and a token as a profile.

Saves the engine URL and a token (and optionally a default database and, for an instance token, the workspace to act in) to the config file, mode 600, as the profile named by --profile (default "default"), and makes it current. The token is read from --token, LUMBUNG_TOKEN, or one line on standard input.

```text
lumbung login [flags]
```

```text
      --db string   default database for commands that need one
```

```sh
lumbung login --url http://127.0.0.1:4870 --db app < token.txt
lumbung login --url https://db.example.com --token lmb_... --profile prod
```

## lumbung object

### lumbung object cp

### lumbung object ls

List objects, with folders from /.

```text
lumbung object ls BUCKET[/PREFIX] [flags]
```

```text
      --limit int   stop after about this many entries (0: all)
  -r, --recursive   list every key under the prefix instead of rolling folders up
```


### lumbung object presign

Print a presigned S3 URL for one object.

Prints a URL anyone can use to GET (or PUT) one object until it expires. It is signed with the token's access key, so the token must have one (`lumbung token create --access-key`).

```text
lumbung object presign BUCKET/KEY [flags]
```

```text
      --expires duration   how long the URL stays valid (default 1h0m0s)
      --method string      GET to download or PUT to upload (default "GET")
```

```sh
lumbung object presign photos/cat.jpg --expires 1h
lumbung object presign uploads/new.bin --method PUT
```

### lumbung object put

Upload a file as an object.

Uploads FILE. When the destination ends with / or names only the bucket, the file's name is appended as the key.

```text
lumbung object put FILE BUCKET/KEY [flags]
```

```text
      --cache-control string   a Cache-Control header to store with the object
      --content-type string    the object's content type (default: guessed from the file)
      --meta stringArray       custom metadata as name=value (repeatable)
```

```sh
lumbung object put cat.jpg photos/2026/
lumbung object put report.pdf docs/q3.pdf --meta owner=finance
```

### lumbung object rm

Delete an object.

```text
lumbung object rm BUCKET/KEY
```

### lumbung query

Run one SQL statement.

Runs one statement with bound parameters in its own transaction. Each --arg binds the next ? placeholder; it is read as JSON (42, 1.5, true, null, "text") when it parses, otherwise as text.

```text
lumbung query SQL [flags]
```

```text
      --arg stringArray   a parameter value; repeat for each ?
      --branch string     branch name or id (default: the database's default branch)
      --db string         database name or id (default: the profile's)
      --read-only         run on a read-only connection
```

```sh
lumbung query "SELECT * FROM users WHERE id = ?" --db app --arg 1
lumbung query "INSERT INTO users (name) VALUES (?)" --db app --branch dev --arg Ana
```

### lumbung shell

An interactive SQL prompt.

Reads SQL until a statement ends with a semicolon, runs it, and prints the result. Ctrl-C cancels a running statement or clears the line; Ctrl-D or .quit leaves. Commands: .tables, .schema [TABLE], .branch NAME, .help, .quit.

```text
lumbung shell [flags]
```

```text
      --branch string   branch name or id (default: the database's default branch)
      --db string       database name or id (default: the profile's)
```

## lumbung token

List, create and revoke API tokens.

### lumbung token create

Create a token; the full token is printed once.

Without --db, --bucket or --grant the token reaches the whole workspace at --access, including what is created later. With admin access it can create and delete databases and buckets there.

```text
lumbung token create [flags]
```

```text
      --access string         read, write or admin (default "read")
      --access-key            also make an S3 access key for the token
      --branch string         limit the token to this branch of --db
      --bucket string         limit the token to this bucket (instead of --db)
      --db string             limit the token to this database (default: the whole workspace)
      --expires-in-days int   expire after this many days (0: never)
      --grant stringArray     reach several things with one token: db=NAME:ACCESS, db=NAME/BRANCH:ACCESS or bucket=NAME:ACCESS (repeat it)
      --instance              make an instance token, which belongs to no workspace
      --name string           what the token is for
```

```sh
lumbung token create --name ci --db app --access write --expires-in-days 90
lumbung token create --name uploads --bucket photos --access write --access-key
lumbung token create --name agent --grant db=notes:write --grant bucket=files:read
lumbung token create --name agent --access admin --workspace agent
lumbung token create --name operator --access admin --instance
```

## lumbung workspace

List, create, change, delete and restore workspaces.

### lumbung workspace create

Create a workspace.

Creates an empty workspace. Limits that aren't passed take the instance's settings for new workspaces. Make its first token with `lumbung token create --workspace NAME`.

```text
lumbung workspace create NAME [flags]
```

```text
      --max-buckets int             most buckets (0: no limit of its own)
      --max-database-bytes string   most space its databases may take together, like 2GiB (0: no limit of its own)
      --max-databases int           most databases, counting the trash (0: no limit of its own)
      --max-object-bytes string     most space its buckets may hold together, like 5GiB (0: no limit of its own)
```

```sh
lumbung workspace create agent --max-databases 20 --max-object-bytes 5GiB
lumbung token create --name agent --access admin --workspace agent
```

### lumbung workspace delete

Move a workspace to the trash, with everything in it.

Moves a workspace to the trash. At once its tokens stop working and its databases and buckets stop answering. It can be restored, with everything in it, until the trash retention passes.

```text
lumbung workspace delete NAME
```
