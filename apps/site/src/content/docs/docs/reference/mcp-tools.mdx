## create_branch

Create a branch as a full copy of another branch (default: the default branch). Changes on it never merge back. Use it to test migrations safely.

| Input | Type | Description |
|---|---|---|
| `database` (required) | string | database name or id |
| `expires_in_days` | integer | delete the branch automatically after this many days |
| `from` | string | branch to copy; defaults to the default branch |
| `name` (required) | string | name for the new branch: lowercase letters, digits and hyphens |

## create_database

Create a database with an empty default branch named main. Needs an instance admin token. Names: lowercase letters, digits and hyphens.

| Input | Type | Description |
|---|---|---|
| `name` (required) | string | lowercase letters, digits and hyphens, starting with a letter or digit |
