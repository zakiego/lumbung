## create_branch

Create a branch as a full copy of another branch (default: the default branch). Changes on it never merge back. Use it to test migrations safely.

| Input | Type | Description |
|---|---|---|
| `database` (required) | string | database name or id |
| `expires_in_days` | integer | delete the branch automatically after this many days |
| `from` | string | branch to copy; defaults to the default branch |
| `name` (required) | string | name for the new branch: lowercase letters, digits and hyphens |

## execute

Run one SQL statement that changes data or schema (INSERT, UPDATE, DELETE, CREATE, ALTER, DROP) in its own transaction. Needs a write token. Prefer testing schema changes on a branch first. Rows from RETURNING are shown up to 1000 rows and about 64 KB.

| Input | Type | Description |
|---|---|---|
| `args` | null or array | values for ? placeholders, in order: strings, numbers, booleans or null |
| `branch` | string | branch name or id; defaults to the default branch |
| `database` (required) | string | database name or id |
| `sql` (required) | string | exactly one SQL statement |
