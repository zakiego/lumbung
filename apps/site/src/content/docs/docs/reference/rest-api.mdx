- Errors are `application/problem+json` with a stable `code`; see [Error codes](/docs/reference/error-codes/).

- Lists take `limit` (1 to 200, default 50) and `cursor`, and return `data` and `next_cursor` (empty on the last page).
- Create endpoints accept an `Idempotency-Key` header: a retry with the same key returns the first response.
- Every response carries `X-Request-Id`.

### Import a database file or SQL dump into a branch

`POST /v1/databases/{db}/branches/{branch}/import`

Send the file as the raw request body. It is built into a new file and checked first: the header, PRAGMA integrity_check, the branch size limit and the same isolation rules as user SQL. The branch only changes when everything passed.

| Parameter | In | Type | Description |
|---|---|---|---|
| `db` (required) | path | string | Database name or id. |
| `branch` (required) | path | string | Branch name or id. |
