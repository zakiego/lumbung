Variants: 1 Product stage (a framed mock of the dashboard comparing a branch with main), 2 Terminal (a CLI session that creates a branch, changes it and queries it), 3 Agent chat (an AI agent working on a branch over MCP). Kept: 2, Terminal. Zaki's pick, no reason given.
